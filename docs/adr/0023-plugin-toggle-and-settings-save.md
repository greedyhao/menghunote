# ADR 0023 — 插件启停单一入口与设置保存模型

> 状态：**已决**（2026-11-19，用户确认：插件总开关之后，插件自己的设置页不再需要开关；
> 设置页底部的「保存模式/relay（重启后生效）」不应出现在所有分类）。
> 关联：ADR 0020（插件边界）、ADR 0021（主题/本机偏好）、
> `docs/notes/ui-refactor-settings-ribbon-sort.md`（设置分类导航与插件页总开关）。

## 1. 背景

设置页拆成左侧分类导航后，「插件」分类提供了模板/日记的总开关（Obsidian 核心插件式），
但模板/日记自己的设置区里仍保留了一个「启用模板 / 启用日记」按钮。两个入口读写同一份
`enabled`，视觉上重复，而且用户容易误以为它们是不同的状态。

同时，设置页底栏固定显示「保存模式/relay（重启后生效）」与「关闭（不保存）」，
这两个按钮原本只服务于 relay 模式/地址的配置。拆分类后它们仍然出现在外观、语言、
模板、日记等所有分类下，看起来像「改主题/改插件也要保存并重启」，与实际行为不符：
这些本机设置是即时写盘、即时生效的。

另一个反复出现的问题是设置字段单击即全选：用户点一下输入框，整段文字变蓝，
继续输入会替换全部内容。设置字段的语义是「继续编辑已有值」，不是「重命名标题」。

## 2. 决策

### 2.1 插件启停只有一个入口

- **唯一开关**：设置 →「插件」页里的 `settings-plugin-<id>-toggle`。
- 开关直接读写插件自己的持久化文件（`templates.json` / `daily-notes.json` 的 `enabled`），
  不建立第二份状态。
- 插件自己的设置分类（模板/日记）**只放配置项**，不再渲染启用开关、状态文本或
  `EnabledChanged` 事件；关闭插件后其分类从左侧导航消失，ribbon 入口同步隐藏。
- 固定 selector `settings-templates-toggle` / `settings-daily-notes-toggle` 及其
  `-state` 文本**移除**；需要断言「没有重复开关」时断言这些 selector 不存在。

### 2.2 设置保存模型按分类区分

- **即时生效的本机设置**（外观、语言、模板、日记、实例默认项、插件开关）：
  改完即写盘/生效；底栏只保留「关闭」`settings-close`，不出现保存按钮。
- **relay 配置**（模式/地址）：仍是显式保存，因为保存后需要重启应用才切换 relay；
  只有「Relay」分类显示 `settings-save`（文案「保存 relay 设置（重启后生效）」）、
  `settings-cancel`（「关闭（不保存 relay 修改）」）、`settings-error` /
  `settings-notice`。其它分类不显示这些控件，也不显示「无错误」占位。
- 底栏不再承担「所有设置统一保存」的暗示；点遮罩/Esc/关闭仍关闭面板，
  即时设置已写盘，relay 未保存的编辑丢弃。

### 2.3 设置字段单击不选中

- 单击设置字段只聚焦并把光标放到末尾（`RenameInput::focus_for_edit` 不再 `select_all`）。
- 需要替换整段时用 `Ctrl+A` 或拖选。
- 该规则适用于模板/日记设置字段与选择器搜索框；侧栏重命名仍保留「进入编辑即全选」的标题语义。

## 3. 后果

- 移除 `TemplatesSettingsEvent` 与 `DailyNotesSettingsEvent::EnabledChanged`；
  `AppRoot` 不再通过事件刷新插件分类，`settings_toggle_plugin` 仍是总开关的唯一写入口。
- 设置页底栏按 `SettingsSection::Relay` 条件渲染；非 relay 分类只有
  `settings-close`。`settings-cancel` 仅表示「关闭且不保存 relay 修改」。
- dev-sync 的 `AppShell` 旧设置页复用同一套插件设置面板，因此也不再显示重复开关；
  它本身没有「插件」总开关页，属于 dev-only 兼容入口（产品用户走 `AppRoot`）。
- 文档/测试中的旧 selector 同步移除；新增 ADR 0023 作为后续插件设置页的约束：
  **插件详情页不得再出现启用开关**。

## 4. 未做

- 不把 relay 保存改成热切换（仍需要重启；这是 ADR 0013 的既定安全边界）。
- 不做设置字段的「按 x 坐标精确定位光标」；本轮只消除全选，光标落在末尾。
- 不新增「设置自动保存失败」的全局 toast；现有各面板的保存提示/错误保留。
