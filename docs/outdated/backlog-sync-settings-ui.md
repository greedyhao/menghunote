> 一个设置入口和底部状态；完整配置/设备管理放到设置页。

## 现状

- `DevSyncPanel` 是根层绝对定位覆盖层（`dev-sync-panel`），启动即存在，
  占右上角、内容很长；
- 同步状态行在侧栏底部（`sync-status` / `sync-status-error`），不在窗口底栏；
- 没有统一“设置”入口。

## 目标交互

### 1. 底部状态栏

- 窗口底部新增一行状态栏（固定高度，右侧对齐）；
- 右侧显示**紧凑同步状态**：图标/圆点 + 短文案（如“同步：空闲/同步中/需处理”）；
- 错误/需处理时用警示色，点击状态打开设置页的“同步”页；
- 不显示 relay 地址、设备列表、按钮；这些只在设置里；
- 无 dev-sync（默认构建）时状态栏该区域不存在。

### 2. 设置入口

- 左下角/状态栏右侧放一个齿轮按钮（`settings-open`）；
- 点击打开**设置页/模态层**，不再是常驻覆盖层；
- 设置页包含分组（首版可先一页）：
  - 同步状态 / relay / 最近错误 / 最近操作；
  - 同步、停止、重试发布基线；
  - 设备列表、移除设备、邀请、批准；
  - 轮换密钥 / 应用轮换 / 恢复码输入；
  - 仍保留 `DEV ONLY / 非生产 / localhost` 固定标识；
- 打开方式：点击齿轮；关闭：Esc、点击遮罩、右上角 ×；
- 设置打开时主编辑器不可误操作（遮罩拦截），但不冻结编辑/同步；
- 首版不做多标签页；设备/安全分区可用纵向分组，后续再拆“同步/设备/安全”页。

### 3. 主界面

- 启动时**不再渲染** `dev-sync-panel` 覆盖层；
- 侧栏不再常驻同步状态行（状态移到底栏）；
- 保留现有 `dev-sync-*` selector，但只在设置打开时存在，headless 测试改为
  “打开设置后断言”；新增 `settings-open` / `settings-close` / `settings-panel`；
- 自动同步、状态刷新、安全暂停等行为不变，只是入口/显示位置变化。

## 约束

- 不改 `DevSyncPanel` 的 worker/命令/持闸逻辑，只改挂载点与外壳；
- secret/邀请 token 仍只在内存/剪贴板，不因设置页而进入布局/日志；
- 同步状态在设置关闭时仍要更新（不能只在打开时 pump）；底栏用只读投影；
- 设置关闭后不销毁 worker/panel（保留实体，避免重建连接/丢状态）；
- 默认构建无 dev-sync 时无齿轮、无同步状态、无设置页；
- UI 真机验收：DPI、模态遮罩、Esc、点击外部、焦点、滚动长设备列表。

## 切片

- **U1**：底部状态栏 + 隐藏常驻面板 + 齿轮 + 设置模态（内容沿用现有面板）；
- **U2**：设置内容分区/滚动/窄窗口适配；状态点击直达同步分区；
- **U3**：邀请/轮换/设备确认在模态里的焦点与错误态打磨。

## 验收

- 启动后主界面没有任何同步覆盖层；
- 右下角状态可见、状态变化自动更新；
- 齿轮打开设置，能完成同步/设备/邀请/轮换现有全部操作；
- Esc/遮罩/× 都能关，关闭后编辑不丢焦点；
- headless：无面板常驻、状态栏存在、设置打开后 `dev-sync-*` 可见；
- 默认构建测试不受影响。
